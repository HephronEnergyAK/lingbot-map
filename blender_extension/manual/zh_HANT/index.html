LingBot Map Reconstruction 0.1.0

本封裝手冊不需網路連線即可使用。擴充功能可將一個本機 MP4 或 MOV Continuous Take 轉換為 Blender 中的彩色 Point Cloud、動畫重建相機與軌跡。

擴充功能負責設定與匯入工作；神經推論在獨立且有限生命週期的 Worker 行程中執行，而非在 Blender 內。開啟本手冊或 LingBot Map 面板不會開始下載。

工作流程

  1. 在支援的主機安裝擴充功能，並完成明確的設定操作。
  2. 儲存 .blend、選擇一個擷取來源、執行預檢，再選擇已通過驗證的設定檔。
  3. 開始重建、監看或取消有限工作，然後匯入完整 Result。
  4. 檢查來源對齊相機與 Point Cloud；明確管理 Results、Dense Predictions、診斷及專案垃圾桶。

工程版限制

0.1.0 是針對 Windows 11 x64、Blender 5.2 LTS、固定原生 NVIDIA 軟體堆疊及明確通過驗證之 GPU 設定檔的工程版。它沒有 WSL backend、即時相機輸入、自訂更新程式、Blender 官方 Extensions 上架或一般平台保證。

在完成 LingBot-Map 與 SkySeg 權重專用授權證據、具授權的 Release Fixture Corpus、完整 Blender 5.2 原生發布套件，以及 RTX 5090 Blackwell 與至少 16 GB 的代表性 Ada 驗證證據之前，1.0.0 仍禁止發布。
