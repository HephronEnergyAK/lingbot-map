交易式匯入

匯入會先完整驗證 Result 路徑、schemas、checksums、array headers、shapes、values、provenance、目標綁定與記憶體容量，之後才配置 Blender 資料。它會建立未連結的 staging Collection，並只在 commit point 連結至所選場景。取消或失敗會移除該次嘗試唯一建立的所有 datablocks；磁碟 Result 不會變更。

自動及一般匯入使用原始且唯一的目標場景。「匯入至」可在確認後使用另一個具有唯一識別的場景。「匯入外部 Result」會驗證使用者選取的外部目錄，並建立沒有生命週期權限的唯讀磁碟參照。

Point Cloud 視覺化

重建 Collection 包含原生彩色 Point Cloud、重建相機、軌跡及重建 Root。來源 RGB 使用 Emission material；信心度顯示使用 Viridis。Radius Scale 與重建 Root scale 都是可逆的 Blender 控制，絕不重寫 Result arrays。

需要 Material Preview 或 Rendered viewport shading 才能檢查 material 色彩。匯入絕不自動變更 viewport shading、exposure、color management 或場景 render engine。

相機與來源對齊檢查

匯入的重建相機會保留 source-space intrinsics、每影格 quaternion pose、linear F-Curves 與凍結的 Timeline Start。除非明確選擇「使用重建相機」，否則不會成為場景相機。來源背景只能以確切來源 checksum 重新連結，且預設隱藏。

36 mm 虛擬 sensor 與動畫 lens 用於重現 horizontal field of view，並不宣稱是實際擷取感光元件。模型裁切導引是暫時且不參與算圖的 overlay。

算圖引擎

最終 Point Cloud 算圖只保證支援 Cycles。非 Cycles 場景仍可匯入，但擴充功能必須提出警告且絕不自動切換引擎。在 Cycles 中，點對 camera、reflection 及 transmission rays 維持可見，同時對 diffuse、volume 及 shadow rays 使用 transparent branch。
