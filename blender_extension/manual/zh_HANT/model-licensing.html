模型來源與授權

封裝的 Model Catalog 會固定每個啟用模型的 upstream repository、immutable revision、filename、byte length、SHA-256、serialization contract、顯示的 SPDX expression、captured license-text identity 及 weight-license evidence status。設定會在明確下載前顯示來源、授權與 checksum。

GPL Blender 擴充功能、Apache-2.0 Worker 邊界、第三方執行環境套件及每個模型產物各有獨立 LICENSE 與 NOTICE 紀錄。絕不假設周邊程式碼 repository 的授權涵蓋 weight file。

模型取得

線上下載與本機匯入只接受與目錄完全相同的長度及 SHA-256。未知 checksums 與任意 checkpoints 都會被拒絕。下載使用 checksum 專屬 staging 與已驗證的 HTTPS resume metadata；只有完整且已驗證的產物會以原子方式發布。工作絕不執行所選外部路徑。

權重專用 1.0 gate

目前 upstream pages 將 LingBot-Map 描述為 Apache-2.0、SkySeg 描述為 MIT，但能證明這些條款涵蓋確切啟用 weight files 的可歸屬證據仍待完成。工程版可使用完全相同的 catalogued checksums 進行開發測試。在兩份權重專用紀錄完整之前，1.0.0 與官方平台提交仍受阻；不得將此 gate 表示為已解決。
