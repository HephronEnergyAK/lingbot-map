Results

Each successful Job publishes one immutable versioned Result under the sibling Project Result Root. Repeated Jobs create additional Results; they never replace an earlier Result or imported Collection. Display names are editable and never establish ownership. Complete mutually consistent Extension metadata controls idempotency and lifecycle authority.

Remove Version deletes only uniquely owned Blender datablocks after explicit inspection; shared data and the disk Result remain. Detached content becomes user-owned and is never recaptured by name or structure.

Dense Predictions

Optional Dense Predictions contain finalized aligned depth and raw confidence chunks. Retention is off by default and makes the Profile Custom. Removing Dense Predictions validates the complete component and moves only dense/ to Project Trash; the core Result and imported content remain usable.

Project Trash

Moving an owned Result, Dense component, or diagnostic to Trash is an explicit recoverable atomic action. Restore requires exact identity, original ownership, and an absent destination; it never overwrites. Permanent deletion inventories direct ordinary content, requires typing DELETE, proceeds one file at a time, and records an inspectable partial-delete state if interrupted.

Trash has no automatic expiry. Uninstall never deletes Projects, Results, diagnostics, or Trash.

External Results and Save As

Save As never migrates Project data. Collections referring to the old Project become External read-only references in the new file. External Results expose no move, restore, Dense removal, or permanent-delete action. Relinking requires the exact recorded Result ID and manifest checksum.
