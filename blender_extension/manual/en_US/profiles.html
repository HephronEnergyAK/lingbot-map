Reconstruction Profiles

Draft uses one camera iteration, 70% confidence, and a one-million-point import budget. Balanced uses four iterations, 50% confidence, and five million points. High uses four iterations, 30% confidence, and ten million points. A Profile is enabled only after its exact capability test succeeds with the required memory headroom.

Advanced settings

Changing Camera Iterations, Confidence Cutoff, Depth Cutoff, Import Point Budget, Dense retention, or another underlying setting makes the Profile Custom. The point budget is a hard output/import limit, not a request to allocate exactly that many points. More than ten million points requires explicit confirmation; fifty million is the absolute limit.

No Profile changes the fixed 518-pixel, patch-size-14 canonical preprocessing crop or weakens source validation.

GPU qualification

Qualification is tied to the selected physical NVML GPU UUID, Runtime, model checksums, pinned stack, and settings. Mutable CUDA ordinals are never stored. A failure does not silently lower settings. Jobs on one GPU UUID are serialized across LingBot Map processes for the same Windows account.

Sky Masking

Sky Masking is optional and uses a separately catalogued Auxiliary Model on CPU. It filters sky point candidates after Reconstruction Model inference; it never changes the model input. It does not detect people, vehicles, or other Dynamic Content, and masks are not retained in the Result.
