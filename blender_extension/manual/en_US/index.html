LingBot Map Reconstruction 0.1.0

This packaged manual is available without a network connection. The Extension turns one local MP4 or MOV Continuous Take into a colored Point Cloud, an animated Reconstruction Camera, and a trajectory inside Blender.

The Extension configures and imports work. Neural inference runs in a separate finite Worker process, not inside Blender. Opening this manual or the LingBot Map panels does not start a download.

Workflow

  1. Install the Extension on a supported host and complete explicit Setup.
  2. Save the .blend, choose one Capture Source, preflight it, and select a qualified Profile.
  3. Start Reconstruction, monitor or cancel the finite Job, then import the complete Result.
  4. Inspect the source-aligned camera and Point Cloud. Manage Results, Dense Predictions, diagnostics, and Project Trash explicitly.

Engineering-release limitations

Version 0.1.0 is an engineering release for Windows 11 x64, Blender 5.2 LTS, the pinned native NVIDIA stack, and explicitly qualified GPU Profiles. It has no WSL backend, live camera input, custom updater, official Blender Extensions listing, or general platform guarantee.

Publication of 1.0.0 remains blocked until weight-specific LingBot-Map and SkySeg license evidence, a licensed Release Fixture Corpus, the full native Blender 5.2 release suite, and representative RTX 5090 Blackwell plus Ada 16 GB-or-more qualification evidence are complete.
