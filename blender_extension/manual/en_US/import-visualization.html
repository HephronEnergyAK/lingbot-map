Transactional import

Import completely validates Result paths, schemas, checksums, array headers, shapes, values, provenance, target binding, and memory capacity before allocating Blender data. It builds an unlinked staging Collection and links it to the chosen Scene only at the commit point. Cancellation or failure removes every datablock uniquely created by that attempt; the disk Result is unchanged.

Automatic and ordinary import use the original unique Target Scene. Import Into may use another uniquely identified Scene after confirmation. Import External Result validates a user-selected foreign directory and creates a read-only disk reference without lifecycle authority.

Point Cloud visualization

The Reconstruction Collection contains a native colored Point Cloud, Reconstruction Camera, trajectory, and Reconstruction Root. Source RGB uses an Emission material; confidence display uses Viridis. Radius Scale and Reconstruction Root scale remain reversible Blender controls and never rewrite the Result arrays.

Material Preview or Rendered viewport shading is needed to inspect the material color. Import never changes viewport shading, exposure, color management, or the Scene render engine automatically.

Camera and source-aligned inspection

The imported Reconstruction Camera preserves source-space intrinsics, per-frame quaternion pose, linear F-Curves, and the frozen Timeline Start. It does not become the Scene camera unless Use Reconstruction Camera is explicitly selected. Source Background can be relinked only by exact source checksum and is hidden by default.

The 36 mm virtual sensor and animated lens reproduce horizontal field of view; they are not a claim about the physical capture sensor. The Model Crop Guide is a temporary, non-rendering overlay.

Render engines

Final point-cloud rendering is guaranteed only in Cycles. A non-Cycles Scene still imports, but the Extension must warn and never switches engines automatically. In Cycles, points remain visible to camera, reflection, and transmission rays while using a transparent branch for diffuse, volume, and shadow rays.
