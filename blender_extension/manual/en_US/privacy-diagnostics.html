Diagnostics

Failed, cancelled, interrupted, and forced termination paths retain bounded diagnostics with stable error codes and validated Job or operation identity. Worker human output rotates through four 16 MiB files. Exceeding 64 MiB records structured truncation while terminal errors, warnings, and bounded tracebacks remain separate.

Diagnostics are retained until an explicit lifecycle action. They are never uploaded automatically.

Portable Diagnostic Report

Export uses a versioned fixed allowlist, strict bounded parsing, and no-follow file identity checks. It never includes Capture Source media, model weights, point arrays, Dense Predictions, masks, partial downloads, staging, caches, or unlisted content. Default export redacts usernames, machine names, absolute paths, environment values, source identifiers, and full GPU UUIDs.

An unredacted report is a one-export opt-in and never expands the allowlist. Existing destinations are not overwritten, including a destination created during publication.

Privacy boundaries

The Extension performs no telemetry, background update check, or implicit upload. Capture Sources remain local and are not copied into Results. Setup network activity occurs only after an explicit online action and respects Blender Online Access. Offline Setup never connects.

Clipboard

Copy Diagnostic Report is the only clipboard behavior. It copies a bounded redacted summary, manifest, and primary structured record. It never copies an unredacted representation, media, model bytes, or arbitrary diagnostic files.
