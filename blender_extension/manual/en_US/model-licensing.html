Model sources and licenses

The bundled Model Catalog fixes each enabled model's upstream repository, immutable revision, filename, byte length, SHA-256, serialization contract, displayed SPDX expression, captured license-text identity, and weight-license evidence status. Setup shows source, license, and checksum before an explicit download.

The GPL Blender Extension, Apache-2.0 Worker boundary, third-party Runtime packages, and each model artifact have separate LICENSE and NOTICE records. A surrounding code repository license is never assumed to cover a weight file.

Model acquisition

Online download and local import accept only an exact catalogued length and SHA-256. Unknown checksums and arbitrary checkpoints are rejected. Downloads use checksum-scoped staging and validated HTTPS resume metadata; only a complete verified artifact is atomically published. Jobs never execute the selected external path.

Weight-specific 1.0 gate

Current upstream pages describe LingBot-Map as Apache-2.0 and SkySeg as MIT, but attributable evidence that those terms cover the exact enabled weight files remains pending. Engineering builds may exercise the exact catalogued checksums for development. Version 1.0.0 and official-platform submission remain blocked until both weight-specific records are complete; the gate must not be represented as resolved.
