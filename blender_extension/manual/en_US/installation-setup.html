Installation

Install the versioned lingbot_map_reconstruction-0.1.0.zip through Blender's Extension manager. Engineering ZIPs come from the HephronEnergyAK fork's tagged GitHub Releases with a published SHA-256 and SBOM. The Extension has no custom updater and never checks for updates in the background.

The package declares only file, network, and clipboard permissions. Network access is used only after an explicit online Runtime or model Setup action; clipboard access is used only by Copy Diagnostic Report.

Setup

The Setup panel independently reports the immutable Worker Runtime, required Reconstruction Model, optional Sky Auxiliary Model, selected physical GPU UUID, and per-Profile qualification. Use Setup Worker Runtime, then explicitly download or import the exact catalogued model bytes, and run Test GPU Profiles.

Runtime construction uses pinned Python 3.10, uv, packages, schemas, and application wheel content. Jobs use a content-addressed published Runtime and never mutate it.

Offline Setup

Offline Setup permits only already verified artifacts in the managed cache. It never falls back to a connection. If an exact artifact is missing, Setup fails with a precise missing-artifact message. Populate the cache through a previous explicit online Setup or provide the exact catalogued local model through Import Local.

Supported host

Native version one supports only Windows 11 x64 and Blender 5.2 LTS. Windows 10, Windows Server, Windows on ARM, compatibility layers, other Blender versions, and WSL are Unsupported with no bypass. GPU support is not inferred from a model-name or VRAM list: each Profile must pass the pinned-stack capability test on the selected physical GPU UUID.
