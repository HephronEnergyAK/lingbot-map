Stable error codes

Stable codes and machine contracts remain invariant English in every language. The localized UI may explain them, but must not translate the code. Include the exact code and a default-redacted Portable Diagnostic Report when requesting support.

Setup errors

setup.runtime.failed means immutable Runtime construction or validation failed. setup.runtime.cancelled means the explicit Setup was cancelled and staging was retained. setup.model.checksum-mismatch means model bytes did not match the catalogued identity. Check host support, Blender Online Access or Offline cache completeness, free disk space, and the exact model source.

Launch and Pipeline errors

launch.worker.failed and launch.worker.bootstrap-failed identify failures before normal Worker status. pipeline.preflight.failed indicates complete media validation failed. pipeline.reconstruction.failed identifies reconstruction failure; inspect its phase, traceback, source identity, GPU status, memory, disk, and structured warnings.

Import and lifecycle errors

import.transaction.failed means import stopped before commit and unique staging datablocks were removed. lifecycle.plan.failed means ownership or preflight planning could not prove a disk action safe. Diagnostic export codes such as diagnostic-export-linked-file, diagnostic-export-race, and diagnostic-export-file-too-large intentionally fail closed.

Troubleshooting checklist

  1. Confirm Windows 11 x64, Blender 5.2 LTS, a selected physical GPU UUID, Ready Runtime/model states, and a qualified Profile.
  2. Save the target .blend; resolve duplicate Scene IDs or imported identities before starting or deleting work.
  3. Use a supported unedited rectilinear MP4/MOV and run Preflight after any source change.
  4. Leave adequate physical memory, VRAM, and Project disk headroom. Close unrelated GPU consumers if qualification reports GPU Busy.
  5. Do not edit active .jobs, Result, diagnostic, or Trash files. Use explicit relink, restore, and retry actions.
  6. Export a redacted report. Opt into unredacted identity only if the recipient and transfer are trusted.
